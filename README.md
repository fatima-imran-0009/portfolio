# portfolio
This is a portfolio project I developed for my 'Tools and Techniques for Data Science' course. I built this interactive web application using Streamlit to demonstrate how raw data can be turned into a functional, user-friendly tool.

The main goal of this project was to apply the core concepts I've learned in my BS Data Science program, focusing on data processing and instant visualization.

Key Features & Tools:



Streamlit Framework: Used to build the front-end and turn Python scripts into an interactive web app.

Python (Pandas & NumPy): Handled the backend data cleaning and transformation logic.
